# Pathfinder 2e – Charakterbogen-Export

Foundry-VTT-Charakter (JSON-Export) → druckfertiger, deutscher Charakterbogen im Stil der
Pathfinder-2-Einsteigerbox, Stufe 1–20.

Das Tool liegt im Ordner [`pf2charakterbogenexport/`](pf2charakterbogenexport/) – Anleitung siehe
[dessen README](pf2charakterbogenexport/README.md). Einfach `pf2charakterbogenexport/index.html`
im Browser öffnen.
